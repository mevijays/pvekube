The disk is added as scsi1, which the guest sees as /dev/sdb (what a Rook deviceFilter: ^sdb$ expects). A worker that already has a scsi1 disk is left unchanged. Because upgrades and resizes replace every worker VM, PVEKube remembers this setting and attaches the disk to the replacement workers when those operations finish. Ceph still has to rebuild its data on a replaced node's new, empty disk — roll workers one at a time and wait for the cluster to be healthy.
