Kubeconfig merge

Combine several kubeconfig files into one you can switch between with kubectl config use-context. Files are checked first — you only get a download once they validate.

Kubeconfigs contain admin credentials. Files are processed in memory for the request only — nothing is saved, cached or logged on the server.

Select several at once (Cmd/Ctrl-click). Any name works — config, *.yaml, *.kubeconfig.

kubeadm names every cluster kubernetes and every user kubernetes-admin, so merging two kubeadm kubeconfigs always hits this. Merging blindly would keep only one cluster's credentials.

Nothing is generated until validation passes.
