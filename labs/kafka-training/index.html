Hands-on course for your devk8s cluster

Learn Apache Kafka from zero, then run it for real

No prior knowledge needed. You will see how data is published to a topic, split into partitions, copied for safety, and read by consumers. Then you will operate and troubleshoot a real 3-broker Kafka cluster running on your Kubernetes.

Who is this for?

Beginner

Never touched Kafka

Start at module 1. Every term is explained with an everyday analogy before any command appears.

Developer

Building with events

Modules 3 and 5 cover producer and consumer design: keys, acks, offsets, delivery guarantees, lag.

Platform / ops

Running the cluster

Modules 4, 6, 7 and 9 cover replication, storage, the Kubernetes deployment, monitoring and failure drills.

The learning path

Go in order. Each module ends with a quiz or lab so you know it stuck.

What you will be able to do

Explain it

  • What a topic, partition, offset, broker and consumer group are
  • Why Kafka keeps messages after they are read
  • How keys decide partitions and ordering
  • How replication survives a broker failure

Operate it

  • Create, inspect and tune topics from the CLI
  • Read consumer lag and fix stuck consumers
  • Set retention and understand disk use
  • Diagnose under-replicated partitions and lost quorum

Your lab environment

Everything in modules 7 to 9 runs against a real cluster already deployed in your devk8s Kubernetes cluster, namespace kafka.

ItemValue
KafkaApache Kafka 4.0.0, KRaft mode (no ZooKeeper), 3 brokers kafka-0..2
Storage5 Gi ceph-block volume per broker
PlacementOne broker per worker node (pod anti-affinity)
Defaultsreplication factor 3, min.insync.replicas=2, 3 partitions, 7 day retention, auto-create topics off
CLI podkafka-client with every Kafka command-line tool
Manifestlabs/kafka/kafka.yaml

If the cluster is not running, redeploy it with kubectl --context devk8s-admin@devk8s apply -f labs/kafka/kafka.yaml.

How to use this course

  • Open this folder's index.html in any browser. It needs no internet, build step or server.
  • Use the simulators: click, break things, kill brokers. You cannot hurt anything here.
  • When a module says Real output the text was captured from your cluster.
  • Your progress and quiz scores are saved in your browser only.
